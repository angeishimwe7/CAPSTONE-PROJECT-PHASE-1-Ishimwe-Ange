# University Management Console

Java + JDBC + PostgreSQL console app (Phase 1 Capstone).

## How to run
1. Create a PostgreSQL database named `university` and run `sql/schema.sql`.
2. Add the PostgreSQL JDBC driver (org.postgresql:postgresql:42.7.4).
3. Set the environment variable `DB_PASSWORD`.
4. Run `Lab3.console.ConsoleApp`.
